Documentation

Learn how to use Nebula CLI effectively

Quick Start

  1. Install Nebula CLI 
    curl -fsSL https://nebula-cli.dev/install.sh | bash
  2. Authenticate 
    nebula auth login
  3. Deploy your first resource 
    nebula deploy my-app

Core Commands

nebula init [project-name]

Initialize a new Nebula project

nebula deploy [resource]

Deploy resources to cloud providers

nebula status [resource]

Check the status of deployed resources

nebula logs [resource]

View logs from deployed resources

nebula destroy [resource]

Remove deployed resources

Configuration

Create a nebula.yaml file in your project root:

project:
  name: my-app
  region: us-east-1

resources:
  - type: compute
    size: standard
    count: 3

  - type: database
    engine: postgres
    version: 15

Supported Cloud Providers

  • Amazon Web Services (AWS)
  • Google Cloud Platform (GCP)
  • Microsoft Azure
  • DigitalOcean
  • Linode
