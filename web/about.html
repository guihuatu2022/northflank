About Nebula CLI

Building the future of cloud infrastructure management

Our Mission

Nebula CLI was created to simplify cloud infrastructure management for developers. We believe that deploying and managing cloud resources should be as simple as running a single command, without sacrificing power or flexibility.

Key Features

  • Multi-cloud support (AWS, GCP, Azure, DigitalOcean, Linode)
  • Declarative configuration with YAML
  • Fast parallel deployments
  • Built-in security best practices
  • Lightweight single binary with zero dependencies

Open Source

Nebula CLI is open source software, released under the MIT License. We welcome contributions from the community and believe in transparent development.
